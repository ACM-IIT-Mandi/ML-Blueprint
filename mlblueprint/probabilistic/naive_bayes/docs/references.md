# References

- Kevin P. Murphy, [_Machine Learning: A Probabilistic Perspective_](https://mitpress.mit.edu/9780262018029/machine-learning/), MIT Press, 2012, Chapter 3, Section 3.5, pp. 82–89 — conditional independence, Gaussian and categorical likelihoods, Laplace smoothing, log-sum-exp, and Multinomial Naive Bayes for word counts.
- [scikit-learn: Naive Bayes user guide](https://scikit-learn.org/stable/modules/naive_bayes.html) — formulas and implementation details for Gaussian, Categorical, and Multinomial Naive Bayes.
- scikit-learn API references: [GaussianNB](https://scikit-learn.org/stable/modules/generated/sklearn.naive_bayes.GaussianNB.html), [CategoricalNB](https://scikit-learn.org/stable/modules/generated/sklearn.naive_bayes.CategoricalNB.html), and [MultinomialNB](https://scikit-learn.org/stable/modules/generated/sklearn.naive_bayes.MultinomialNB.html) — production implementations used in the comparison tests.
